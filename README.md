# Korean_imperfectiveNLI

This dataset tests if language models display teleological bias for undetermined events. Stimuli translated into Korean.

## Source
This dataset is adapted from ImperfectiveNLI (Ma & Miyao, 2026).
Original repository: https://github.com/boleima/ImperfectiveParadox
